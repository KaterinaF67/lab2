# ЛР №2 — методы оптимизации, вариант 19

**Федоровская Е. С., Б24-517**

## Задача

Вариант 19: транспортная задача с запретом части маршрутов.

Модель содержит 4 склада, 6 магазинов, ограничения запасов и спроса, пропускные способности маршрутов и 5 запрещённых дуг. Цель — минимизировать суммарную стоимость перевозок.

Вариант и seed:

```text
V = 1 + ((17*N + 7*Q + Y) mod 20) = 19
seed = 10000 + 100*Q + N = 10125
```

## Что реализовано

- данные варианта в CSV и воспроизводимая генерация с seed 10125;
- LP-модель транспортной сети через HiGHS (`scipy.optimize.linprog`, `highs-ds`);
- схема сети с потоками и пропускными способностями;
- независимая NumPy-проверка баланса каждого узла, границ дуг, запрещённых маршрутов и целевой функции;
- сценарий отказа самой загруженной дуги;
- отдельный сценарий перегрузки: пропускная способность наиболее критичной насыщенной дуги уменьшается на 20%;
- сценарий роста спроса на 20% с интерпретацией `infeasible`;
- поиск насыщенных маршрутов и анализ их теневых цен;
- узловые потенциалы из двойственных оценок балансовых ограничений;
- сравнение с жадной эвристикой «сначала самые дешёвые маршруты»;
- дополнительное задание: целочисленная версия с неделимыми рейсами и сравнение LP/MILP;
- CSV-результаты, solver logs, графики и PDF-отчёт.

## Математическая модель

Для разрешённого маршрута `(i, j)`:

```text
x[i,j] >= 0  — объём перевозки
c[i,j]       — стоимость единицы перевозки
u[i,j]       — пропускная способность
```

Цель:

```text
min sum(i,j) c[i,j] * x[i,j]
```

Ограничения:

```text
sum(j) x[i,j] = supply[i]     для каждого склада i
sum(i) x[i,j] = demand[j]     для каждого магазина j
0 <= x[i,j] <= capacity[i,j]  для каждой разрешённой дуги
x[i,j] = 0                    для запрещённых маршрутов
```

## Запуск

```bash
python main.py
```

## Дополнительное задание

Выбран вариант из методических указаний: целочисленная версия с неделимыми рейсами. В основной LP-модели `x[i,j]` непрерывны; в расширении одна единица `x[i,j]` трактуется как одна стандартная неделимая партия (рейс), а поток ограничен условием `x[i,j] in Z_+`. Поэтому, например, дробная пропускная способность 18.6 допускает не более 18 целых рейсов. MILP решается через `scipy.optimize.milp` и HiGHS. Сохраняются `milp_solution.csv`, `verification_milp.json`, `milp_summary.json`, `lp_milp_flow_changes.csv`, `solver_milp.log` и график `lp_vs_milp.png`.
